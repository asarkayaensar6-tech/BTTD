# V30.47: correct assistant product concentration

The previous helper divided gross item-line value by collected revenue. A 100 TL item line with a 50 TL payment could report 200%. The helper now uses total recorded item-line value as its denominator and explicitly states this is not collection share. Payment-only partial records do not dilute product mix. No financial record is mutated.

This branch contains the standalone helper and executable regression tests, not the complete BTDD application. The complete V30.47 ZIP derives from V30.46 and is delivered separately. Do not treat this branch as a runnable Windows package.

The full package additionally passed 52 existing frontend checks, 18 data/day-close tests and 108 canvas geometry scenarios plus 4 compatibility checks. These are not browser screenshot or hardware tests; real iPhone/Windows/drawer and visual layout remain unverified. Cash-button theme behavior is unchanged pending clarification.
